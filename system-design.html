Layered Clean Architecture — roadmap-core-service

Request flows strictly top-down. No layer skips allowed. No business logic in controllers. No Prisma calls in services.

🌐

Maps HTTP verb + path to controller handler. Zero logic.

Architectural Trade-offs & Design Decisions
DecisionChosen ApproachAlternativeReasoning
ArchitectureMicroservices + Docker ComposeMonolithFault isolation; AI service in Python, backend in Node.js; independent scaling
AI WorkflowLangGraph StateGraphLCEL Linear ChainConditional routing + self-correction loops impossible in linear chains
Queue SystemRedis + BullMQKafka / RabbitMQRedis already in stack. BullMQ provides job retries & scheduling without extra infra
ORM StrategyPrisma ORMRaw SQL / SequelizeType-safe auto-generated client, $transaction API, migration management
CachingSHA-256 hash-keyed Redis (7d TTL)No cache / DB cacheIdentical goal+params = identical roadmap. Saves >70% LLM cost. <15ms vs ~3.5s
Self-CorrectionRetry loop (max 2) + Circuit BreakerInfinite retryBalances output quality vs API cost. Prevents runaway spend.
Adaptive Re-schedulingUpdate future tasks ONLYRegenerate full roadmapPreserves completed history for streak integrity. No extra LLM cost.
Rate LimitingRedis Token Bucket (10 req/min)In-memory limiterStateless, distributed across restarts. Atomic INCR+EXPIRE avoids race conditions.
Non-Functional Requirements (NFRs)
⚡ Performance
  • Cached roadmap: <15ms response
  • Fresh AI roadmap: ~3.5s end-to-end
  • Task completion endpoint: <50ms
  • Redis streak lookup: O(1)
🛡️ Security
  • JWT Bearer Token auth at gateway
  • Helmet HTTP security headers
  • CORS origin whitelisting
  • bcrypt password hashing
  • Rate limit: 10 req/min per user
🔄 Resilience
  • Redis down → graceful cache bypass
  • Gemini error → circuit breaker fires
  • Worker crash → BullMQ auto-retry
  • Prisma $transaction rollback on fail
📈 Scalability
  • Each service scales independently
  • Redis caching cuts LLM calls >70%
  • BullMQ worker horizontally scalable
  • Stateless gateway = load-balancer ready
🏗️ Maintainability
  • Strict 4-layer clean architecture
  • Prompts separated from LangGraph nodes
  • Pydantic schemas enforce AI contract
  • AppError middleware centralised
💰 Cost Efficiency
  • >70% Gemini API cost saved via cache
  • LangGraph retry cap: max 2 attempts
  • BullMQ batches notifications async
  • Alpine Docker images = minimal RAM

🤖 2. How Many Agents Work Inside the AI System?
Instead of relying on one generic, hallucination-prone prompt, PathPilot uses a 3 + 1 Specialized Multi-Role Agent Pipeline:

#	Agent Name	Core Responsibility	Output
1	Roadmap Architect Agent	-----Analyzes the student's high-level goal, skill level, daily bandwidth (e.g., 2 hrs/day), and target days to build structured weekly milestones.	High-level weekly phases & progression milestones.
2	Micro-Task Decomposer Agent	------Slices each milestone into 15–30 minute bite-sized atomic daily tasks with difficulty ratings (EASY, MEDIUM, HARD).	Discrete daily actionable tasks (Day 1 to Day N).
3	Resource Curator Agent------	Pairs every daily task with curated documentation links (e.g., official docs, tutorials) to eliminate search fatigue.	Verified learning URLs & contextual task notes.
4	Adaptive Rebalancer Agent (Triggered on Delay)-------	Activates when a student falls behind by 2–3 days. Rebalances future incomplete tasks across the remaining timeline without touching completed history.	Recalculated timeline & dynamic task schedule.
